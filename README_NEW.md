# Harsh Patel Portfolio

A modern, minimalist portfolio website built with React and Vite, featuring a sophisticated black, white, and grey color scheme.

## Features

- 🎨 Modern minimalist design with monochromatic color scheme
- ⚡ Fast performance with Vite
- 📱 Fully responsive design
- 🎭 Smooth animations and transitions
- 🖱️ Custom cursor effects
- 🎯 Interactive project showcase
- 📧 Contact information and social links

## Technologies Used

- React 18
- Vite
- Framer Motion (for animations)
- Modern CSS with custom properties
- Intersection Observer API

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This site is configured for GitHub Pages deployment. The built files will be in the `dist` directory.

```bash
npm run build
```

Then push to GitHub Pages or your hosting service of choice.
